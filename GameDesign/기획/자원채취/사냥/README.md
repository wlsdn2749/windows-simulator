## 2. 산업 정체성

| 항목 | 값 |
| --- | --- |
| **심리 정의** | **도전 · 목표 지향** ⚠️ 제안 |
| 투자 비유 | 적립식 목표 투자 — 모아서 한 번에 쓴다 |
| 한 줄 | **여기서 모은 것으로 보스에 간다** |
| 회당 산출 | 중간 ⚠️ |
| ~~특별보상~~ | ⚠️ **층 폐지 (2026-07-30).** 뿔·모피·보스 티켓의 경로 미정 |
| 고유 메커니즘 | **사냥터 선택 + 보스** |
| 플레이어 개입 | 사냥터 선택 |

### ⚠️ 실패 폐기로 기존 정체성이 사라졌다

사냥은 원래 **"대부분 실패하지만 성공하면 크다"** (실패율 85%)였다.
**실패가 전 산업에서 폐기되면서 이 축이 통째로 없어졌다.**

| 사라진 것 | 대체 |
| --- | --- |
| 실패율 85% = "드물게" | **사냥터 선택** |
| 성공 시 대량 = "한 방" | **보스** — 모아서 한 번에 터뜨리는 구조 |
| 실패 시 소모품 손실 | (소모품 자체를 유지할지 재검토) |

**사냥은 이제 "한 방"이 아니라 "축적 후 도전"이다.**
다른 4개 산업이 *채취 루프 안에서* 완결되는 반면,
**사냥만 루프 바깥의 콘텐츠(보스)로 이어진다.** 이것이 사냥의 유일무이한 축이다.

### 낚시와의 대비

| | 낚시 | 사냥 |
| --- | --- | --- |
| 심리 | **확실한 도파민** | **도전 · 목표 지향** |
| 시간 감각 | **지금 당장의 만족** | **나중을 위한 축적** |
| 보상 체감 | 자주, 작게 | 티켓이 쌓이는 진행감 |
| 개입 지점 | 없음 | 사냥터 선택 |
| 루프 | 채취에서 완결 | **보스로 이어짐** |

두 산업이 이제 **정확히 반대편**에 선다. 실패율로 갈랐을 때보다 대비가 선명하다.

### 3.1 사냥터 (확정) — **= 사냥 레벨** (2026-08-01)

**사냥터는 [산업 레벨](../산업레벨.md)로 구현한다.** 5종 전부가 같은 구조를 쓰므로
사냥만 `FieldTID`라는 별도 축을 두지 않는다.

| | 이전 표기 | 현재 |
| --- | --- | --- |
| 축 이름 | `FieldTID` (사냥터) | **`IndustryLevel`** (사냥 레벨) |
| 정의 테이블 | `HuntingFieldTable` | `IndustryLevelTable`의 사냥 행 |
| 드랍 시트 | `HuntingBasicTable` (사냥터별) | `HuntingBasicTable.IndustryLevel`로 갈린다 |

> **"사냥터"라는 이름은 UI·연출에서 그대로 쓴다.** 데이터 축만 통합된다.

**사냥터마다 드랍 테이블이 다르다.** 사냥터 선택 = 무엇을 모을지 선택.

| 축 | 사냥터별로 다르게 둘 수 있는 것 |
| --- | --- |
| 보상 매핑 | 같은 `Rare`라도 사냥터마다 다른 산출물 |
| ~~특별보상 내용~~ | 층 폐지 — 뿔·모피는 희귀도 롤로 편입 검토 |
| **보스 티켓 종류** | 사냥터별로 다른 보스로 이어질 수 있다 |
| 해금 조건 | 상위 사냥터를 후반 목표로 |

> **주기·실패·희귀도 분포가 전부 공통인 지금, 사냥터는 "산출물이 다른 세트"로만 갈린다.**
> 상위 사냥터가 단순히 더 좋기만 하면 하위 사냥터는 죽는다.
> **기대값을 비슷하게 두고 "무엇을 모으는가"로 갈라야** 선택이 성립한다.
> (상위 보스로 가려면 상위 사냥터의 티켓이 필요한 구조면 자연히 해결된다)

### 3.2 소모품 — 재검토 필요

기존 기획은 "실패 시 소모품(미끼·화살) 손실"이었다. **실패가 없어져 이 규칙이 무의미하다.**

| 안 | 내용 | 평가 |
| --- | --- | --- |
| A. 소모품 폐기 | 사냥도 다른 산업처럼 비용 없이 돌아간다 | 단순. 다만 사냥의 "비용" 감각이 사라짐 |
| B. 판정당 소비 | 30초마다 소모품 1개 소비 | 하루 2,880개. **소모품 수급 노동이 된다 (P1 위반)** |
| C. 보스 도전 비용으로 이전 | 채취는 무료, **보스 도전에만** 소모품·티켓 소모 | **권장** — 비용을 능동적 행위에만 붙인다 |

**C안을 권장한다.** 방치 구간은 비용 없이 두고, 플레이어가 능동적으로 선택하는
보스 도전에만 비용을 두면 P1·P2를 지키면서 "대가"의 감각이 남는다.

## 4. 보스 (신규 · 상세 미정)

**보스 티켓을 모아 도전하는 콘텐츠.** ⚠️ 티켓 획득 경로는 미정이다 (특별보상 폐지).

```
사냥 (방치) → 보스 티켓 축적 → [플레이어가 원할 때] 보스 도전 → 보상
```

### 4.1 왜 중요한가

[`기획평가.md`](../../기획평가.md)의 **R3(후반 목표 부재, 🔴)** 에 대한 첫 번째 답이다.

- 이 게임은 승패 조건이 없고, 대체 목표가 "자원 축적"뿐이었다.
- 특성을 다 찍으면 할 일이 사라지는 구조였다.
- **보스는 "특성을 다 찍은 다음"에 놓을 수 있는 목표**다.
- 동시에 **채취 루프 바깥의 유일한 콘텐츠**이므로 게임에 층이 하나 생긴다.

### 4.2 ⚠️ P1을 지키는 선

보스는 **능동적 행위**라 이 게임의 대원칙(P1 주의를 뺏지 않는다)과 긴장 관계에 있다.
아래 선을 지켜야 컨셉이 훼손되지 않는다.

| 규칙 | 내용 | 이유 |
| --- | --- | --- |
| **도전 시점은 플레이어가 정한다** | 티켓은 쌓아두고 아무 때나 쓴다. 만료 없음 | 시간 압박이 생기면 P1 위반 |
| **실시간 조작을 요구하지 않는다** | 자동 전투 또는 결과 정산형 | 반응 속도를 요구하면 "업무 중 플레이"가 깨진다 |
| **실패해도 잃는 것은 티켓뿐** | 보유 자원·성장은 절대 잃지 않는다 | P2 |
| **놓쳐도 손해가 없다** | 기간 한정 보스 같은 건 두지 않는다 | 접속 강제 금지 |

> 이 4개를 어기는 순간 보스는 "바탕화면 위젯 방치 게임"에 붙은 이물질이 된다.
> **보스는 방치의 보상이지, 방치를 중단시키는 장치가 아니다.**

### 4.3 결정해야 할 것

- 보스 전투의 형태 (자동 전투 / 스탯 비교 / 확률 판정 / 미니게임?)
- 보스 보상의 정체 (고유 아이템? 특성? 거래 가능?)
- 보스 종류와 난이도 단계 — 사냥터별로 다른 보스인가?
- 티켓 종류가 하나인가, 보스마다 다른가?
- 전투에 플레이어의 무엇이 반영되는가? (특성? 장비? 누적 자원?)
- 재도전 제한이 있는가?

> 보스가 구체화되면 **별도 시스템 문서**(`GameDesign/기획/보스/README.md`)로 분리하고
> [`게임기획코어.md`](../../게임기획코어.md) 3장 시스템 지도에 행을 추가한다.
> 지금은 사냥의 산출물로만 존재하므로 여기 둔다.

| `HuntingBasicTable` | `DropTID`(키), **`IndustryLevel`**, `ItemTID`, `Weight` — 레벨(사냥터)별 산출물 |

  유저 DB의 별도 컬럼이 아니라 슬롯 행에 들어간다 — 슬롯마다 다른 사냥터를 돌릴 수 있다.

## 7. ✅ 완료 — `ItemType.Hunting` 추가 (2026-07-28)

**`Hunting`은 값 `5`로 들어가 있다.** 이 장은 오래 "선행 작업 · 값 `7`로 추가"로 남아 있었다
(2026-08-02 정정).

```
None=0, Farming=1, Fishing=2, Mining=3, Logging=4, Hunting=5, Misc=6, Special=7, Max
```

**당시 판단과 결과:**

| | 이 문서의 계획 | 실제 |
| --- | --- | --- |
| 값 | `7`로 **뒤에 붙인다** | **`5`로 중간에 삽입**됐다 |
| 결과 | — | `Misc`·`Special`이 한 칸씩 밀렸다 |

- **되돌리지 않는다.** 지금은 `t_user_workstation_slot.industry`가 이 정수를 저장하고 있어,
  값을 옮기면 이미 적힌 행의 뜻이 바뀐다.
- 당시에는 `ItemType`을 저장하는 DB 컬럼이 없어 실제 피해가 없었다.
- **"enum은 뒤에만 추가한다"는 규칙은 앞으로에만 적용된다.**
  → [게임기획코어](../../게임기획코어.md) 4장 식별자 규칙 · [아이템](../../아이템/README.md) 1.2

> 1차 산업 5종이 `1~5`로 연속돼 읽기는 좋아졌다. 대가는 위의 규칙 위반 한 번이다.
