# T-007 인벤토리·재화 UI

## 배경

서버는 인벤토리와 재화(골드)를 이미 보내고 있는데 표시할 화면이 없다.
채취로 아이템이 쌓여도 유저가 볼 방법이 없으면 채취 자체가 의미를 갖지 못한다.

| 패킷 | 내용 |
| --- | --- |
| `S_InventoryResponse` | 로그인 시 인벤토리 전체 스냅샷 |
| `S_UpdateItemResponse` | 아이템 증감 |
| `S_CurrencyResponse` | 재화 보유량 — **스냅샷과 변경이 같은 패킷** |

## 할 일

- [x] 인벤토리 목록 — `ItemTable`에서 이름을 읽어 표시 (`InventoryPanelUI` + `InventorySlotView`)
- [x] 증감 반영 — `S_UpdateItemResponse`
- [x] 재화 표시 — `S_CurrencyResponse`는 **증감이 아니라 확정 잔액**이므로
      재화 종류로 **덮어쓰기**만 하면 된다. 더하지 않는다 (`StatePanelUI`)
- [ ] 희귀도별 색상 — `Enum.xlsx`에 이미 정의돼 있다 → **남았다. 아래 참조**

## 완료 조건

채취 결과가 도착하면 인벤토리 수량이 늘어나는 것이 화면에서 보이고,
재접속해도 같은 값이 나온다.

> ✅ **충족 (2026-08-03).** 가챠 지급 규칙이 "총량 덮어쓰기"로 통일되면서
> 화면 수량과 서버 스냅샷이 어긋날 여지가 사라졌다 (깃허브 이슈 #8).

## 남은 것

- **희귀도별 색상**만 안 됐다. `InventorySlotView`는 이름·수량 두 줄뿐이고 테두리 색이 없다.
  기능이 아니라 **표시 품질**이라 완료 조건에는 걸리지 않는다.
  아이콘 작업(T-015)에서 칸 프리팹을 다시 손댈 때 같이 하는 편이 싸다.
