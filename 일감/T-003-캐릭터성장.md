# T-003 캐릭터 레벨·경험치를 성장에 반영

## 배경

`t_character`에 `level`·`exp` 컬럼을 만들어 두고 `Character` 객체까지 싣고 있지만
**아무 데서도 읽지 않는다.** 지금 캐릭터 속도는 `CharacterTable`의 고정 적성값으로만 정해져서,
레벨이 올라도 아무 일도 일어나지 않는다.

컬럼만 있고 쓰지 않는 상태가 길어지면, 나중에 성장식을 붙일 때
"기존 유저의 exp를 어떻게 해석할 것인가"라는 마이그레이션 문제가 따라온다.

## 할 일

- [ ] 경험치 획득 경로 결정 — 채취 판정마다? 퀘스트? 별도 재화 투입?
- [ ] 레벨업 곡선 결정 (필요 exp 테이블)
- [ ] 레벨 → 적성/속도 기여식 결정 — 적성이 오르는가, 적성과 별개 배수인가
- [ ] `CharacterTable`과의 관계 정리 — 적성이 테이블 고정값인데 레벨로 바뀌면 무엇이 진실인가
- [ ] 기본 캐릭터(TID 1)가 같은 규칙을 따르는지 결정
- [ ] 구현 + `ResolveSlotSpeed` 반영

## 완료 조건

레벨이 오르면 슬롯 속도가 실제로 달라지고, 그 값이 재접속 후에도 유지된다.

## 막고 있는 것 / 선행 일감

- 성장식·획득 경로가 전부 기획 미정이다 (게임기획코어 5장 `캐릭터 시스템 전체 ❌ 미작성`)
- T-010(캐릭터 기획 문서화)에서 함께 정하는 게 자연스럽다
