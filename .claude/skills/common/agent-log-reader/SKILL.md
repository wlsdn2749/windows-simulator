# Agent 작업 로그 참조 (작업 전 필독)

> 코드 작업을 **시작하기 전에**, 같은 영역의 이전 작업 로그(`.claude/Agent/`)를
> 먼저 읽어 과거 맥락·결정을 반영한다.
> 짝이 되는 스킬은 [`agent-log-writer`](../agent-log-writer/SKILL.md)(작업 후 로그 기록)다.

---

## 트리거 — 언제 로그를 읽는가

**코드/설정 파일을 수정하는 작업에 착수하기 전.** (기능 추가·변경·삭제, 리팩토링,
버그 수정, 스키마/패킷/데이터 변경 등) 실제 편집을 시작하기 전에 수행한다.

## 하지 않아도 되는 경우

- 파일을 바꾸지 않는 순수 질의응답/설명
- `.claude/Agent/`에 아직 로그가 없을 때 (폴더가 비어 있으면 그대로 진행)

---

## 절차

1. `.claude/Agent/README.md`의 `INDEX`를 읽어 어떤 로그가 있는지 훑는다.
2. 이번 작업과 **같은 영역/파일/키워드**에 해당하는 로그를 골라 본문을 읽는다.
   - 판단이 애매하면 관련 있어 보이는 로그는 넉넉히 읽는다.
   - INDEX가 없거나 부실하면 `.claude/Agent/*.md` 파일명을 직접 확인한다.
3. 로그의 **주요 결정·후속 작업·주의사항**을 이번 작업에 반영한다.
   - 이미 내려진 결정을 근거 없이 뒤집지 않는다. 바꿔야 하면 이유를 함께 남긴다.
   - "후속 작업/주의사항"에 적힌 TODO·함정을 우선 확인한다.

---

## 충돌·상충 시

- 로그의 결정과 현재 코드가 다르면, **먼저 사용자에게 상황을 알리고** 어느 쪽을
  기준으로 할지 확인한다. 임의로 한쪽을 밀어붙이지 않는다.
- 로그 내용이 명백히 낡았다면(파일이 이미 사라짐 등), 그 사실을 답변에 명시한다.

---

## 작업 후

작업을 마치면 [`agent-log-writer`](../agent-log-writer/SKILL.md) 스킬에 따라
이번 작업 로그를 `.claude/Agent/`에 남긴다. (읽기 → 작업 → 기록 순환)
