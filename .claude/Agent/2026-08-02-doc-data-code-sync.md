# 기획 문서·엑셀·코드 불일치 전수 정리

## 목적 / 배경

문서·엑셀·코드가 어긋난 곳을 전수 조사하고 정리했다.
[문서 그래프 도입](2026-08-02-doc-graph-propagation.md)에서 만든 재귀 전파 규칙의 첫 적용이다.

**원인은 하나로 모인다 — 엑셀 파이프라인이 빨라서 데이터만 먼저 나갔고,
그 사실이 문서에도 코드에도 반영되지 않았다.**

## 변경 내용

**문서 정정** (12개 문서)

- 아이템 — **30종 → 156종**(산업 150 + 가챠 6). 레벨별 TID 표 신설
- 자원채취·게임기획코어 — `Hunting` enum "값 7로 추가 필요" → **`5`로 반영 완료**
- 사냥 7장 — "선행 작업"을 완료 기록으로 재작성 (계획 `7` vs 실제 `5`의 경위 포함)
- `ItemRarity` → `GlobalRarity` 잔존 6곳 (게임UI·기획평가·자원채취·낚시·채굴·T-015)
- 낚시 — **오프라인 24h 감쇠·요일 보너스가 살아 있었다.** 둘 다 폐지 반영.
  드롭 시트 현황도 옛 정보(6행·`DropTID 101~`)라 38행·`1101~`로 정정
- 농사·벌목 — "더미 데이터 `A`/`B`/`C`" → 실 데이터. `CropTable` 구상이 실제 시트와 달랐다
- 벌목 — "오프라인 중 재생"이 성립하지 않는 질문이 됐음을 명시(미결로 남김)
- 산업레벨 6장 — **"구현 완료" 표기를 "엑셀까지 완료 · 서버 미구현"으로 정정**

**일감** — T-017(오동작 명시 · 최우선) · T-012(시작 슬롯) · T-018/T-015(종수) · README

**기획평가** — R21(데이터가 코드보다 앞섬) · R22(문서 전파 누락) 추가

## 주요 결정 / 근거

- **코드는 고치지 않았다.** 드롭 레벨 필터·`JudgeCost`·시작 슬롯 수 셋 다 T-017/T-012 범위이고,
  특히 드롭 필터는 `WorkStationSlot`에 레벨 필드가 없어 **단독으로 고칠 수 없다**
  (필터를 걸 축 자체가 없다). 대신 일감과 문서에 오동작을 명시했다.
- **낡은 서술을 지우지 않고 취소선 + 정정 사유로 남겼다.** 이 저장소의 기존 문법이고,
  "왜 그렇게 알고 있었는가"가 남아야 같은 착오가 반복되지 않는다.
- **기획평가 앞부분(2026-07-26 작성분)은 고치지 않았다.** 업데이트 섹션이 누적되는 구조라
  앞부분을 고치면 평가 이력이 왜곡된다. 새 섹션으로만 덧붙였다.

## 후속 작업 / 주의사항

- 🔴 **서버가 지금 잘못 동작한다 — 가장 중요한 미결.**
  `DropTableCatalog`가 `IndustryLevel`을 읽지 않아 **Lv1 슬롯에서 Lv5 아이템이 나오고,
  희귀도 가중치 총합도 레벨 수만큼 부풀어 있다.** 이 상태의 채취 결과로
  T-008(희귀도 분포)·T-009(회당 산출)를 실측하면 안 된다. → 일감 T-017
- `User.DefaultSlotCount = 1`인데 확정값은 **2**(상한 8 검증도 없다).
  곡선(T-012)을 기다릴 필요 없이 지금 고칠 수 있는 항목이다.
- ⚠️ **검사기 버그 두 개를 잡았다** — 자세한 내용은
  [그래프 도입 로그](2026-08-02-doc-graph-propagation.md)에 이어 적었다.
  ① `바뀌면 갱신` 블록을 그래프에서 제외하지 않으면 간선이 양방향으로 번진다.
  ② `> 작성일: A · 최종 업데이트: B` 한 줄 문서(기획평가)에서 앞의 작성일이 잡혀
  문서가 영원히 낡아 보였다.
- **남은 경고 11건은 확인 완료다** — 특성·퀘스트·진행 및 성장·거래는 열어 봤고
  이번 변경의 영향이 없었다. 근거는 [문서관계도 5.1](../../GameDesign/기획/문서관계도.md)에 표로 남겼다.
- 밸런스 수치(희귀도 분포·회당 산출·`BasePrice`)는 **하나도 건드리지 않았다.** 전부 미정 상태 유지.
